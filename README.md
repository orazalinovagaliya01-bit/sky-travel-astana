# Sky Travel Astana

Адаптивный сайт-подборщик туров из Казахстана. Турист указывает месяц, бюджет и состав семьи и сразу видит подходящие страны с ориентировочной ценой, а затем отправляет заявку в WhatsApp.

- `index.html` — весь сайт в одном файле (HTML + CSS + JS).
- `PRD.md` — требования к продукту.

## Настройка

В начале скрипта в `index.html`:

- `CONFIG` — телефон, WhatsApp, Telegram, Instagram, email, адрес, лицензия (помечены `TODO`);
- `COUNTRIES` — направления, цены, сезоны, погода;
- `HOT_TOURS` — горящие туры;
- `REVIEWS` — отзывы.

Страница заявок: `index.html#admin` (ссылка «Вход для менеджера» в подвале). Заявки хранятся в браузере устройства, где их оставили.
